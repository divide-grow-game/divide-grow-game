분신 키우기 업데이트 파일

포함 파일
- index.html : 보스전 UI, 공격/반격 애니메이션, 실시간 전투 기록
- server.js : 보스 공격 계산 및 능력치 저장 API
- package.json / package-lock.json : 기존 프로젝트 설정

적용 방법
1. 기존 프로젝트 폴더를 통째로 다른 곳에 복사해 백업하세요.
2. 이 압축 파일의 index.html과 server.js를 기존 프로젝트의 같은 이름 파일에 덮어쓰세요.
3. 기존 game.db 파일은 삭제하거나 교체하지 마세요. 서버가 시작될 때 stats_json 열을 자동으로 추가합니다.
4. 명령 프롬프트에서 프로젝트 폴더로 이동한 뒤 npm start를 실행하세요.
5. 웹사이트에서 온라인 PvP 탭으로 서버에 접속하세요. 보스전 능력치가 서버에 등록됩니다.
6. 분신이나 장비를 바꾼 뒤에는 서버 접속 버튼을 다시 눌러 최신 능력치를 등록하세요.
7. 보스전 탭에서 보스를 선택하고 입장한 다음 공격하기를 누르세요.

능력치 규칙
- 최대 체력(hp), 치명타 확률(crit)은 변동하지 않습니다.
- 공격력, 방어력, 속도, 치명타 피해, 명중률, 회피율, 관통력, 흡혈, 재생력, 행운은 매 공격마다 각각 원래 능력치에서 -30~+30 사이로 변동합니다.
- 변동 후 값은 0보다 작아지지 않습니다.
- 보스전의 변동 계산은 서버에서 처리합니다.

주의
- JavaScript 문법 검사는 통과했습니다. 이 실행 환경에는 프로젝트 npm 패키지가 설치되어 있지 않아 실제 서버 실행/다중 접속 테스트는 수행하지 못했습니다.
- game.db는 기존 플레이어와 보스 기록을 보존하기 위해 압축 파일에 넣지 않았습니다.
