분신 키우기 - 업데이트 버전

[포함 파일]
- index.html : 게임 화면
- server.js : 온라인 PvP 매칭 및 공용 랭킹 서버
- package.json : 서버 실행 설정
- README.txt : 실행 설명서

[이번 업데이트]
- 전투력 및 12개 능력치만 표시
- 기본 전투력은 12개 기본 능력치의 평균이며, 최대값은 99999999999999999999999999999999999999999
- 장비 보너스로 얻는 추가 전투력은 기본 전투력 상한과 별도로 합산되어 상한을 넘어갈 수 있음
- 기본 전투력과 각 기본 능력치의 최대값: 99999999999999999999999999999999999999999
- 매우 큰 능력치는 BigInt 기반으로 저장/계산해 정밀도 손실 방지
- 분신 최대 15개 생성 및 선택
- 장비 50,000종을 전체 세로 목록으로 표시 (무기, 갑옷, 투구, 장갑, 신발)
- 장비 등급 1~15: 목록 아래쪽으로 갈수록 등급과 성능, 가격이 높아지며 15등급이 가장 좋음
- 전투 1~10,000,000단계: 이전 단계 승리 여부와 관계없이 원하는 단계 선택 가능
- 선택한 단계에 맞춰 적정 전투력 참고 범위를 표시 (1단계 1~10, 이후 단계는 단계²×10을 상한으로 계산)
- 승리 시 단계에 비례한 골드 획득, 패배 시 단계에 비례한 골드 손실
- 장착 장비는 전투 성능과 추가 전투력 모두에 영향을 줌
- 수동 저장 및 불러오기
- 온라인 PvP 매칭 및 공용 랭킹 서버 포함

[Windows 실행 방법]
1. Node.js LTS를 설치합니다: https://nodejs.org/
2. 압축을 푼 폴더에서 주소 표시줄에 cmd를 입력하고 Enter를 누릅니다.
3. 명령 프롬프트에서 다음 명령을 실행합니다.

   npm install
   npm start

4. 브라우저에서 http://localhost:3000 을 엽니다.
5. 분신 생성 탭에서 이름과 외형을 정해 분신을 만듭니다.
6. 장비 전체 목록 탭에서 장비를 살펴보고 구매할 수 있습니다.
7. 전투 탭에서 1~10,000,000 사이의 원하는 단계를 입력해 전투합니다.
8. 진행 상황 보관은 수동 저장 버튼을 누릅니다.

[실제 온라인 멀티플레이]
서버 코드는 포함되어 있지만, 다른 네트워크의 사용자도 접속하려면 인터넷에서 접속 가능한 호스팅 서비스에 서버를 배포해야 합니다. 모든 사용자가 같은 서버 주소를 사용해야 공용 랭킹과 PvP 매칭이 공유됩니다.

[프로토타입 참고]
현재 온라인 PvP는 서버에서 전투력 기반으로 승패를 판정하는 기본 매칭 프로토타입입니다. 계정 인증/비밀번호, 치트 방지, 서버 측 전체 캐릭터 저장 및 장비 동기화, 실시간 전투 애니메이션, 운영자 도구와 백업은 아직 구현되지 않았습니다. 공개 서비스로 운영하기 전에는 반드시 인증과 보안 기능을 추가해야 합니다.


[추가 업데이트]
- 장비 목록은 위에서 아래로 1등급에서 15등급으로 올라가며, 등급이 높을수록 능력치와 가격이 높아집니다.
- 기본 전투력은 장비를 제외한 12개 기본 능력치의 평균입니다. 어떤 기본 능력치를 성장시켜도 기본 전투력이 오르며, 12개 능력치가 모두 최대일 때 기본 전투력도 최대값에 도달합니다. 장비 추가 전투력은 별도 합산됩니다.
- 온라인 PvP는 랜덤 상대 찾기 또는 접속 중인 플레이어의 닉네임을 입력해 직접 대결할 수 있습니다.
- 닉네임 대결은 상대가 같은 서버에 접속 중이고 최근 60초 내 활동한 상태여야 합니다.
